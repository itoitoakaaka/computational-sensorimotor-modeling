# External Output Plan

## Aim

Convert the current computational sensorimotor modeling work into a small external research output without creating a new participant experiment.

## Candidate contribution

**Working theme**

> Trial-by-trial computational modeling of human sensorimotor adaptation across environmental conditions

Core contribution:

- fit interpretable state-space parameters
- estimate trial-by-trial error-correction gain
- compare conditions with the same model
- separate measured behavioral effects from model-dependent interpretation
- optionally connect behavioral latent states to EEG/SEP measures

## Realistic first target

### INTERACTION 2027

The symposium accepts work on interaction analysis, modeling, sensing, AI agents, wearable systems, and other human-computer interaction topics.

A realistic format for an early-stage computational extension is the interactive/poster track, which accepts 2-6 page papers.

Current published schedule:

- conference: 2027-03-01 to 2027-03-03
- interactive/poster submission deadline: 2026-12-25

This should only be pursued if it does not interfere with doctoral completion.

## Minimum publishable package

1. one clear research question
2. participant-level trial-by-trial data
3. one transparent baseline
4. one state-space model
5. parameter recovery or simulation validation
6. condition/group comparison
7. uncertainty estimates
8. one main figure showing behavioral trajectories + model fit
9. one main figure showing fitted parameter distributions
10. limitations that distinguish descriptive data from model-dependent interpretation

## Decision rule

Doctoral completion has priority.

Do not start a new experiment for this project before the dissertation is secure. Reuse existing behavioral data, or keep the repository as a methodological demonstration until the degree work is finished.
